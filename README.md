# Madrid by Mood

A mood-based guide to Madrid for university students. Pick a feeling (Relax, Nature, Social, Romantic, Hidden, Free) and get a short list of real places with an approximate price, a neighbourhood and a directions link.

**Live site:** https://slevyieu2025-del.github.io/madrid-by-mood/

## Built with
Plain HTML, CSS and vanilla JavaScript. No libraries, no backend. Saved places use `localStorage`.

## Files
- `index.html` – the page shell (pages are shown by the script: Home, Explore, Place, Saved, About)
- `css/styles.css` – colours, type and layout
- `js/data.js` – the 24 places and 6 moods
- `js/main.js` – filtering, cards, saving and navigation
- `404.html` – page not found

## Credits and limits
- Artwork is original abstract illustration. Add real photos with licence and credit before submitting.
- Prices and opening times are approximate and not live-checked.
- The list is curated, not complete.
